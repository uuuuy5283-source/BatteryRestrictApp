# تقييد البطارية

تطبيق أندرويد يقيّد تشغيل التطبيقات في الخلفية (توفير البطارية) عن طريق شيزوكو، ويرجّعها لو عايز.

## تحميل الـ APK

بعد ما يخلص بناء GitHub Actions، الملف ينزل هنا:

https://github.com/uuuuy5283-source/BatteryRestrictApp/releases/latest

الرابط المباشر للملف:

https://github.com/uuuuy5283-source/BatteryRestrictApp/releases/latest/download/BatteryRestrict.apk

## التثبيت

1. حمّل `BatteryRestrict.apk` على الموبايل.
2. اسمح بالتثبيت من مصادر غير معروفة لو طلب الموبايل.
3. افتح التطبيق واتبع الخطوات جواه (تثبيت شيزوكو، تشغيله، ثم منح الصلاحية).
4. اختر التطبيقات واضغط «تقييد المحدد». «إرجاع المحدد» يرجّع الإعداد.

المتطلبات: أندرويد 8 أو أحدث، وتطبيق [Shizuku](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api).
